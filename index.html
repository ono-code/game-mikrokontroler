ATmega8535 adalah mikrokontroler 8-bit CMOS berdaya rendah berbasis arsitektur AVR RISC dengan memori Flash 8KB, EEPROM 512B, dan SRAM 512B.

Fitur Utama: 40 Pin, 32 I/O Line terprogram
Port: PORTA (ADC), PORTB, PORTC, PORTD

Simulasi Logika Register I/O (DDRx, PORTx, PINx)

Di mikrokontroler AVR, pengaturan mode input/output dan logika pin dikendalikan melalui 3 register utama.

Pilih Port AVR:
0x00 (Semua Input)

Bit = 1 → Output | Bit = 0 → Input

0x00

Jika Output: Bit=1 (HIGH +5V), Bit=0 (LOW 0V). Jika Input: Bit=1 (Pull-up Aktif).

0x00

Membaca kondisi fisik tegangan nyata pada kaki/pin mikrokontroler.

#include <mega8535.h>

// Pin 0 mendeteksi tegangan HIGH (+5V)
}
